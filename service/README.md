# SM CHIP · обслуживание Zeekr

Tilda T123 + статическая страница. Контакты: +7 902 354-40-30, +7 (8412) 72-40-30; Пенза, Ладожская, 1а, корпус 3.

## Клиентский сценарий

Модель → исполнение → работы → масло/жидкость → стоимость → печать. Масла ДВС для 8X 1400 и 9X: DFE / ECS 0W-20 по подбору RAVENOL, с проверкой по VIN. Для редукторов предлагается продукт выбранного агрегата. В каждой позиции есть вариант со своими материалами, при котором учитывается только работа. Неизвестный объём не подменяется нулём.

Материалы = объём × цена упаковки / литраж упаковки, округление до копеек. Полные канистры не начисляются. Цена работы: ДВС 2000 / 3000 ₽ без / со снятием защиты; передний редуктор 2500 ₽, каждый задний 2500 ₽; ВВБ 3000 ₽; контур ДВС 2000 ₽; тормозная жидкость 3000 ₽; фильтры по комплектации 1000 ₽. Запчасти фильтров, уплотнения и промывочный расход исключены.

## Достоверность

Официальная страница Zeekr Lebanon (https://www.zeekrlife.com/en-lb/policy) указывает Zeekr-approved glycol-type coolant и DOT 4. Руководства 001 / X подтверждают DOT 4. Универсальный заводской номер допуска антифриза для всех китайских 8X / 9X открытыми документами не установлен. Характеристики HTC (MB 325.0 / 326.0, VW TL 774-C) и ETC (VW TL 774-L / G12evo) обозначены как спецификации продуктов RAVENOL, а не одобрения Zeekr. Применимость по каждому контуру согласуется по VIN.

Общий basic из каталога не присвоен контуру ВВБ. Объём батарейного контура оставлен неизвестным до VIN/сервисных данных. Для 9X Hyper контур ДВС 7,8 л — справочный каталог. Сервисный расход может отличаться. 8X 900 не получает автоматически литраж 1400. Два отдельных задних узла 9X считаются отдельно; число масляных полостей сдвоенного узла 8X подтверждается до работ.

Редукторы каждые 20 000 км — рекомендация SM CHIP для наших условий, отдельно от заводского графика.

## Прайс

Проверка официальных упаковочных SKU каждые 6 часов: .github/workflows/ravenol-prices.yml, service/automation/update_prices.py. Клиент получает service/prices.json с main при загрузке и раз в 30 минут. Новые позиции: ECS 4 л / 12096 ₽ / 1111102-004; HTC готовый −40°C 5 л / 3455 ₽ / 1410121-005. Источники — официальные карточки RAVENOL, проверены поиском 30.10.2026; прямое получение актуальных цен не подтверждено (тайм-ауты источника). Дата неуспешной попытки не становится датой проверки. При ошибке сохраняются предыдущие цены и показывается краткая пометка. Парсер проверяет SKU, фасовку, название и положительную рублёвую цену.
