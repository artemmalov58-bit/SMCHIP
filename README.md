# SM CHIP — Zeekr

Адаптивная страница русификации и адаптации Zeekr в Пензе.

## Запуск

Раздать каталог `dist` любым статическим HTTP-сервером. Сборка, Node.js и сторонние библиотеки не требуются.

- `dist/index.html` — HTML, изолированные стили и JavaScript.
- `dist/assets/` — локальные оптимизированные изображения WebP.

## Возможности

Выбор семи моделей и другого автомобиля; подбор услуг с итогом для звонка; копирование запроса с ручным резервным вариантом; FAQ; мобильное меню и панель звонка; доступные фокус-состояния; поддержка уменьшенного движения; SEO и AutoRepair JSON-LD.

Заявки никуда автоматически не отправляются. Запись осуществляется по телефону. Сервер, личные данные посетителя и аналитика не используются.

## Данные бизнеса

Телефоны и адрес сохранены из исходника владельца: +7 902 354-40-30, +7 (8412) 72-40-30, Пенза, ул. Ладожская, 1а, корпус 3. Фиксированные цены, длительность установки, гарантии и совместимость конкретных версий не предоставлены; не выдуманы.

## Изображения

Фотографии взяты из изображений, на которые ссылался исходник владельца: https://www.zeekr-cars.com/ . Оптимизированные копии размещены локально. Фотографии не выдаются за выполненные работы. Право использования изображений необходимо учитывать перед коммерческим размещением; открытая лицензия не подтверждена.

## Проверка

Проверены JavaScript-синтаксис, внутренние якоря, загрузка изображений, переключение моделей, синхронизация выбора с подбором услуг, ручное копирование в HTTP-среде и меню на телефоне. Отображение проверено в Chrome на настольной ширине и в iframe шириной 320, 390 и 768 px. Проверка реальных звонков и записи не выполнялась.
